# SIA-Infinity Bot Integrity & Evidence Policy v0.1

SIA-Infinity is designed to precompute relevance, not deception.

## Core contract

The universal Blogger runtime should expose the same article truth and the same meaningful navigation to human visitors and machine crawlers.

SIA may improve retrieval with server-rendered semantics, structured data, Primary Silo relationships, contextual internal links and adaptive Fibonacci-KNN recall. It must not create a different factual page for a crawler.

## Runtime rules

The v0.1 integrity guard rejects the following patterns from the universal theme/runtime:

- named-crawler branching in the public theme
- `navigator.userAgent` or server-style user-agent branching used to change article truth
- hidden prompt-injection-like instructions
- anchors hidden directly with `display:none`, `visibility:hidden` or `font-size:0`
- automatic promotion of semantic similarity to factual support
- automatic `supports_claim=true` behavior

Legitimate hidden data containers used by SIA for labels or configuration are not links and remain allowed.

## Evidence-aware relations

SIA separates semantic relations from evidence relations.

### Semantic relations

These may be inferred from the symbolic graph:

- `related`
- `same_entity`
- `same_silo`
- `same_content_type`
- `shared_facet`
- `shared_label`
- `title_pattern`

A related item generated by the current v0.1 engine is explicitly marked:

```json
{
  "relation_types": ["related", "same_entity", "same_silo"],
  "evidence_status": "semantic_only",
  "supports_claim": false
}
```

### Evidence-only relations

These relation types are reserved for a future explicit evidence layer and are not inferred from similarity:

- `supporting`
- `source_reference`
- `contrasting`

A high semantic score does not make an article a source, proof, citation or contradiction.

## Adaptive recall remains unchanged

SIA still uses:

```text
Semantic Similarity
        ↓
Adaptive Fibonacci K
        ↓
Golden-Ratio Rank Weighting
        ↓
Recall Score
        ↓
Relevance Admission
```

The evidence policy is applied after semantic relation discovery: recall decides what is similar enough to return, not what is true.

## Public graph policy

Every generated graph includes a `relation_policy` object with the principle:

```text
similarity_is_not_evidence
```

The browser adapter also exposes relation/evidence state as `data-sia-relation-types` and `data-sia-evidence-status` attributes on rendered related links for transparent debugging.

## Theme integrity marker

The normalized universal XML contains the project metadata marker:

```html
<meta name="sia-bot-integrity" content="same-content-semantic-parity-v0.1" />
```

This is SIA project metadata only. It is not a standard search-engine directive and does not claim a ranking benefit.

## Design principles

> Precompute relevance, preserve truth.

> Recall finds similarity. Evidence determines support.

> Eligibility is not indexing, ranking or citation.

## Version

This policy belongs to the public SIA-Infinity AI Blogger Template **v0.1**. The public version remains v0.1 until the first stable release.
