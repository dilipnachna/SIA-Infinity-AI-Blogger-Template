# SIA-Infinity AdSense Setup v0.1

SIA keeps the universal Blogger theme publisher-neutral. The repository must not contain a real AdSense publisher ID (`ca-pub-...`) or a real ad unit ID.

## Available Blogger Layout zones

The normalized v0.1 theme exposes three optional sections:

```text
sia-ad-top
sia-ad-bottom
sia-ad-feed
```

### `sia-ad-top`

Visible on individual posts and static pages before the main Blog1 content.

### `sia-ad-bottom`

Visible on individual posts and static pages after Blog1 content and before supporting widgets.

### `sia-ad-feed`

Visible on multiple-item views such as Home, Label, Archive and Search after the post feed and before supporting widgets.

The zones do not modify the proven Blog1 post loop and do not inject ads between individual post cards.

## Add an ad from Blogger Layout

1. Install the latest normalized `theme/SIA-Infinity-AI-Blogger-Template-v0.1.xml`.
2. Open **Blogger → Layout**.
3. Find the desired SIA ad zone.
4. Choose **Add a Gadget**.
5. Use the Blogger AdSense gadget when available, or use an HTML/JavaScript gadget with the ad-unit code provided by your AdSense account.
6. Save the layout.

An empty SIA ad zone renders no default Advertisement placeholder.

## Example responsive ad unit

Use only code generated for your own AdSense account. A generic structure looks like this:

```html
<ins class="adsbygoogle"
     style="display:block"
     data-ad-client="ca-pub-XXXXXXXXXXXXXXXX"
     data-ad-slot="YYYYYYYYYY"
     data-ad-format="auto"
     data-full-width-responsive="true"></ins>
<script>
(adsbygoogle = window.adsbygoogle || []).push({});
</script>
```

Do not copy the placeholder IDs above into production.

## Auto Ads

Auto Ads are independent of the three manual SIA zones. If a Blogger site is connected to AdSense and Auto Ads are enabled for that site, SIA does not block or replace them.

When a site-wide AdSense loader is required, use the code generated by that site's AdSense account. Do not commit a publisher-specific loader to the shared SIA repository.

## Recommended operating modes

### Auto Ads only

Enable Auto Ads for the site and leave all three SIA manual zones empty.

### Manual ads only

Use one or more SIA zones and keep Auto Ads disabled if you want deterministic placements.

### Hybrid

Use Auto Ads plus one or two carefully selected manual SIA zones. Avoid excessive ad density and verify the layout on mobile before expanding placements.

## Portability rule

A fork may customize its own private or site-specific theme, but the upstream universal SIA v0.1 XML remains free of real publisher IDs and real ad-unit IDs.
